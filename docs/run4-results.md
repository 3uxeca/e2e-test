## 2. 정성 평가

### stage1 — 더 두꺼워짐
사전 검증 메모 절이 추가되면서 페이지별로 자동 로드 동작·클릭 인터셉트·
검색 키워드·모달 단계·다운로드 트리거를 **직접 도구로 확인**하느라
turns가 84로 올랐다. 토큰 한도(50k) 안에는 여유 있음.

### stage2 — 동일
1턴/추론only 패턴 유지. 도구 호출 없음. **여전히 Sonnet 다운그레이드의
가장 안전한 후보.**

### stage3 — 의미 있게 좋아짐
- 자가수정 6→3으로 절반.
- 동시에 spec 자체가 **풍부해짐**: 정렬 토글, 페이지 네비게이션 왕복,
  행 0개 모달 검증, 첫 행 결정론 단언(date/time/level/code) 등 10단계.
- stage2의 잘못된 가정(`전체 + KPI` 키워드 매칭 0건)을 stage3가 즉시
  발견해 `메시지 + 1출국장`으로 변경 — stage1의 사전 검증 메모가 stage3
  실측 보정의 입력으로 직접 작용.
